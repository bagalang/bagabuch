# Начални салда и счетоводни периоди

По образец на `secret/su-doxis` (`opening_balances.rs`, `accounting_periods.rs`),
напаснато към нашия сметкоплан (номера по НСС, `analytic_type`).

## Начални салда

Не са обороти. Живеят в `opening_balances`, **не** се пишат в дневника
(същата логика като вътрешния протокол: да не се надува оборотната ведомост).

Екран `/opening-balances`. Година + редове по сметка.

### Страна според вида на сметката (НСС)

Първата цифра на номера, не US GAAP (там 1 = актив; при нас 1 = капитал).

| Клас | Примери | Нормална страна |
|------|---------|-----------------|
| 1 Капитал | 101, 121 | кредит |
| 2 ДМА | 201 | дебит |
| 24 Амортизация | 241 | кредит (коректив) |
| 3 Запаси | 304 | дебит |
| 40 Доставчици | 401 | кредит |
| 41 Клиенти | 411 | дебит |
| 4531 / 4532 | ДДС покупки / продажби | дебит / кредит |
| 5 Финансови | 501, 503 | дебит |
| 6 Разходи | 601–603 | дебит |
| 7 Приходи | 702 | кредит |
| друго | 8, 9, неясен 4xx | дебит **или** кредит |

Редът е само едната страна — не и двете.

### Аналитичност (`accounts.analytic_type`)

- `counterpart` (401, 411) — задължителен контрагент
- `product` (304) — задължителен продукт + количество
- `none` — само сметката

Обобщена таблица в екрана групира по вид (капитал, ДМА, запаси, …).
Общо дебит трябва да е равно на общо кредит.

Редакция/изтриване се отказва, ако януари на тази година е затворен.

## Периоди

Екран `/accounting-periods`. Календарни месеци на годината.

Липсващ ред = **отворен** (като su-doxis). Затварянето записва
`status=closed`. Отварянето връща `open`.

Затворен месец спира:

- `POST /v1/invoices/{id}/post` (по `accounting_month`)
- ръчен запис в дневника (по `entry_date`)
- амортизация (по `period`)
- потвърждение на вътрешен протокол (по `doc_date`)

Чернови на фактури още могат да се пазят; осчетоводяването е ключалката.
su-doxis показваше периодите, но не заключваше поста — тук го правим.
