# Конвенции, които чупят нещата ако се забравят

## Filesize gate 600

`.baga` файл над ~600 реда не минава. Затова схемата е `schema_pg_a/b/c`
(+ boila близнаци), а големите action файлове се цепят
(`fixed_assets` / `fixed_assets_ops`, `internal_docs` / `internal_docs_confirm`,
`invoices` / `invoices_post` / `invoices_print`).

Преди да надуеш файл — `wc -l`. `invoices.baga` вече е на ръба.

## BoilaSQL

- **Едно `=` в WHERE.** Второ равенство (AND колона =) е ненадеждно
  („повторно = условие“). Вторият филтър е в приложението: партиди по
  обект, ДДС тип по запис, курс `date <=` след `ORDER BY date DESC`.
- `ALTER TABLE ADD COLUMN` е **само nullable**. Затова dual наборът стои:
  Postgres миграцията има `NOT NULL DEFAULT`, boila — гола колона.
- Качените `CREATE TABLE` не се пипат.
- Транзакции: `bb_begin` / `bb_commit` / `act_err_rb` около
  фактура, пост, ръчен запис, протокол.

## Числа

Пари и количества са стрингове през целия стек (`bagadecimal`). Не слагай
float в JSON. ЕИК и фактурни номера с водещи нули са TEXT — не ги пращай
като числа.

## Дати (`chronobaga`)

Съхранение и JSON са само ISO `YYYY-MM-DD` или финансов `YYYYMMDD`.
ДДС период / счетоводен месец е ISO `YYYY-MM`. Печат на фактура и ДДС
дневник на екрана са български `dd.mm.yyyy` (`dt_to_bg` / `formatBgDate`).
Не пиши `30/08/2026` и не гадай locale. OCR на фактура: `dt_parse_invoice`,
после пак ISO в базата.

## Route id

Стабилни цели числа в `routes.baga`. Нова група взима празен диапазон
(не размествай старите). `GET …/next-number` преди `GET …/{id}`.

## UI

- български е дефолт, английски втори; ключовете са в `frontend/lib/i18n.ts`
  (и двата речника)
- тема светла/тъмна от самото начало
- частичен PATCH: липсващо поле = не пипай, не нулирай
- **търсачка** в списъците (клиентски филтър върху заредените редове) —
  `CrudPage` (фирми, сметкоплан, контрагенти), стоки, дневник, вътрешни
  документи, начални салда, фактури
- **икон-бутони** за ред в таблица/списък: молив = редакция, кошче = изтрий,
  око/печат/активирай/история — `frontend/components/IconButton.tsx`,
  клас `.btn-icon` + `.icon-actions`. `title` / `aria-label` носят текста
  (подсказка при посочване)
- основните действия остават с надпис: Създай, Запази, Осчетоводи, Потвърди

## TLS към външни HTTPS

Котва = **прекият издател**, не root. Хардкодната в кода; override:
`BAGABUCH_VIES_ANCHOR_FILE`, `BAGABUCH_ECB_ANCHOR_FILE`,
`BAGABUCH_MISTRAL_ANCHOR_FILE`. Виж [architecture.md](architecture.md).

## Референция

`secret/inv` и `secret/su-doxis` са образец. su-doxis има кореспонденция
„Вътрешен трансфер“ Дт 302 / Кт 304 — **нарочно не я копираме**.
`inv` печата фактура като „приемо-предавателен протокол“ към клиент
(без цени) — това е друг документ, външен, не между обекти.
