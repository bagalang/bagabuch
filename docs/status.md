# Състояние (към 2026-08-30)

> за всеки ред.

## Готово и се ползва

- фирми, активна фирма, настройки + SAF-T реквизити
- търговски обекти и поделения, собственици, предприятия-майки
- кочани за изходящи документи (вкл. `internal`)
- сметкоплан, контрагенти + VIES (адресът се дели към SAF-T с Mistral 3B),
  стоки/услуги, мерки, основания за 0% ДДС
- Mistral API ключ по фирма (Настройки → Интеграции)
- сканиране на фактури (покупки/продажби): евтин Mistral OCR → чернова с
  редове (не запис по сметки); търсачка за наш артикул; мапинг по контрагент
- фактури по ППДДС + проформа, печат, UBL, осчетоводяване с изписване
- склад: WAC / FIFO / LIFO, партиди, наличност по обект
- вътрешен приемо-предавателен протокол (стоки + ДМА, без дневник)
- дневник (от пост и ръчен), ДДС дневници и клетки, SAF-T XML експорт
- ДМА: категории ЗКПО, амортизация (счетоводна+данъчна), преоценка,
  преместване по обект, консервация, снемане, история
- валутни курсове от ЕЦБ
- начални салда по НСС клас и аналитичност (без запис в дневника)
- счетоводни периоди: затваряне спира пост/ръчен запис/амортизация/confirm
- търсачка в списъците (контрагенти, фирми, сметкоплан, стоки, дневник, …)
- икон-бутони за редакция/изтриване и сродни действия в таблиците
- тема, BG/EN, JWT скелет

## Нарочно отложено (куката е там)

- отчет печалба / приходи / разходи по обект — `journal_lines.location_id`
  се пише при пост на фактура
- сторно на потвърден вътрешен протокол
- обект на ръчен запис и на амортизация
- SAF-T движения на стоки по обект
